# Aju Util Web

Versão **web** do app de utilidades para Aracaju.

Funciona no **navegador do celular** (Safari, Chrome) — sem precisar de Mac ou Xcode.

## Como usar

1. Abra o link do GitHub Pages (quando ativado)
2. Ou abra `index.html` direto no navegador
3. Adicione à tela inicial para ficar como app

## Recursos

- Busca
- Emergência rápida (ligar com um toque)
- Favoritos (salvos no navegador)
- Dicas de saúde
- Offline básico (Service Worker)
